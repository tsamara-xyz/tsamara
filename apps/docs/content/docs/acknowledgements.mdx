- [Solana](https://solana.com) and its Token-2022 program: frozen-by-default accounts, the
  transfer hook, metadata on the mint and the permanent delegate.
- [Anchor](https://www.anchor-lang.com) for the compliance program, and
  [LiteSVM](https://github.com/LiteSVM/litesvm) for testing it in-process.
- [Carbon](https://github.com/sevenlabs-hq/carbon) for the indexer.
- [Sumsub](https://sumsub.com) for identity verification, in sandbox mode.
- [Bun](https://bun.sh), [Hono](https://hono.dev), [Next.js](https://nextjs.org),
  [TanStack](https://tanstack.com) Query and Table, [Astro](https://astro.build) and
  [Biome](https://biomejs.dev) for the rest.

These docs are [Fumadocs](https://fumadocs.dev) on Next.js, starting from the
[tailwind-variants-docs](https://github.com/heroui-inc/tailwind-variants-docs) template by
HeroUI, MIT. The content, the branding and the deployment are Tsamara's.
